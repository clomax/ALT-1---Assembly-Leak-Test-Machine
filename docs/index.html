ALT-1 Assembly & Leak Test Machine

A simulated special purpose machine that presses a cap onto a cast valve body and leak tests the assembly. It is controlled by an IEC 61131-3 program running on the OpenPLC soft PLC, and a plant simulator takes the place of the machine.

View source on GitHub Functional description (.pdf)

Overview

The hypothetical product is a small cast aluminium valve body. A cap is pressed onto the body, and the assembly is pressure decay leak tested before it is released.

Stations

  1. Load and identify The operator loads a part and presses Start. The machine assigns a serial number.
  2. Cap fit and press A pneumatic cylinder presses the cap on. Position sensors confirm travel, with a timeout fault.
  3. Leak test The machine runs a test on a leak test instrument and handles pass, fail, timeout and instrument fault.
  4. Unload Good parts would go to the good lane. Failed parts would go to a locked reject bin.

Control system architecture

Soft PLC
OpenPLC runtime v4 in Docker
Languages
Ladder (main program), Structured Text (function blocks)
Scan
Cyclic task, 20 ms
Plant link
Modbus TCP, localhost:5020, 9 inputs, 5 coils, 1 register

Two layers

The ladder layer owns the physical I/O, permissives and interlocks, and is the only layer that drives outputs. The Structured Text sequence only sets request bits. It can ask for the cylinder to extend; the interlock layer decides whether it does.

Plant simulator

plant_sim.py pretends to be the machine. It is a Modbus TCP server written in standard-library Python, with an operator panel and a terminal command line. It also injects faults, such as a jammed press, a slow press or a stuck sensor. 

python3 sim/plant_sim.py
python3 sim/plant_sim.py --no-gui --port 5020 --travel 0.4

Factory acceptance test

The functional description defines 30 tests, FAT-01 to FAT-30, each with an action and an expected result. They were run by hand against the plant simulator, driving the machine from its operator panel and checking how the PLC responded. Faults that would be hard to create on demand, such as a jammed press, a slow press or a stuck position sensor, were created with the simulator's fault injection.

Status outputsFAT-26 to 30 The fault, reset and leak test lamps show the true state, and the serial number reaches the panel.

What testing found

Through testing I discovered that a part could be taken off the pallet during the leak test without any fault being shown, so an untested part could leave the machine unnoticed. As a fix, the PLC now drives a leak test lamp, Lamp_LeakTest, during step 40, and the Unload function is disabled while a leak test is being conducted. FAT-28 checks both.
